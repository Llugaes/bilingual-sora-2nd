# 三套界面翻新方案

这是用于选择视觉与信息结构的交互设计稿，尚未接入正式 Qt 界面。现有安装版本和游戏配置不受影响。

## 打开

直接用浏览器打开 `index.html`，或在仓库根目录执行：

```powershell
.venv/Scripts/python.exe -m http.server 8876 --bind 127.0.0.1 --directory docs/ui-concepts
```

访问 `http://127.0.0.1:8876/`。页面顶部可切换 A、B、C，设置只保存在当前页面内存中。

## 方案

| 方案 | 视觉 | 信息结构 | 取舍 |
| --- | --- | --- | --- |
| A 游击士手册（推荐） | 纸色、青绿、少量金线 | 左侧分为游戏内容和工具本身 | 有游戏气质，目录占横向空间 |
| B 清透面板 | 冷白、深蓝 | 三组任务，设置与效果并排 | 简洁直接，窗口需要较宽 |
| C 夜间控制台 | 石墨、薄荷绿 | 四个折叠分组，保留当前值摘要 | 切页少，展开多项后需要滚动 |

共同约定：实心圆代表选中，空心圆代表未选中；启用开关位于首屏顶部；主副语言两列；工具界面语言归入工具外观；检查更新、自动更新、帮助和关于位于独立菜单；悬浮条保留齿轮和最小化；窗口关闭也最小化到托盘，退出放入托盘右键菜单；透明度只作用于背景。

## 验证与边界

已在浏览器查看三套布局，检查单双语切换、语言示例、更新独立菜单、折叠分组、透明度；透明度为 100% 时背景透明、文字不透明。JavaScript 语法检查通过，浏览器检查未发现错误日志。

连接状态、更新、快捷键录制、系统托盘与退出均为交互示意，不代表真实游戏或系统操作。示例排版用于观察设置效果，不代替游戏内富文本渲染验证。正式界面实现等待方案选定。

`option-a.jpg`、`option-b.jpg`、`option-c.jpg` 是对应方案的浏览器截图。

## A 修订稿：游戏原版资源

用户选择 A 的布局，要求直接使用游戏资源。打开 `game.html` 查看第二版；旧 `index.html` 和三张截图保留作为初稿对照。此轮仍是视觉试作，尚未修改正式 Qt 窗口。

原版资源来自用户本机游戏 `pac/steam/image.pac`，使用 `note000`、`window3`、`camp000` 图集的局部，保留原纹理与透明通道。`game-assets/provenance.json` 记录每张切片的来源、区域和原文件 SHA-256。没有改写游戏文件、附加进程或改动配置。

用带 Pillow 的 Python 执行 `extract_game_assets.py --game-dir <游戏目录>` 可重新生成切片。游戏美术版权归 Nihon Falcom Corporation。

交互规则更新：移除 Pin；悬浮条只保留设置与最小化；设置窗口关闭和 Esc 均最小化到托盘；单击托盘恢复，右键菜单提供彻底退出。页面底部有独立托盘模拟入口，方便在浏览器里验证行为。
