## 2026-10-04 本地候选：使用零原点测量

候选仅供本地实机测试，未公开发布。旧检查把子控件结束边界直接设为单行高度，遗漏了真实解析器的坐标语义。

实测使用独立 DEV 目录，复制已校验的运行依赖、配置和当前映射缓存。设置标题、悬浮条与托盘明确标记 DEV；开发目录不含正式安装清单，更新器不会覆盖它。启动前正常退出正式版工具，防止两个工具同时连接。正式版文件与配置分别保留，实机验收仍为待完成。

- `0x58709f` 在零原点测量副文；`0x58714a` 复用同一个子上下文，重新初始化后绘制。初始化会清空边界，因此必须在这个调用的入口读取前一次测量。
- `parse_text` 的 `0x587824/0x58782e` 将边界起点设为零。位于后续行的绘制结果包含页面 Y 位置；把这个包围范围作为新增行高，会递归加入前几行的高度。这是 0.3.34 的窗口膨胀原因。
- 候选仅为已接管的双语多行副文保存零原点高度。主文原注音仍单独计算；副文的整行高度已含原注音，不再重复相加。无需增加解析调用、逐帧扫描或控件名称白名单。

隐藏原生宿主运行正式回调、C 桥接和真实初始化机器码；测量与绘制复用同一子上下文。48 组组合覆盖测量／绘制、初始 Y 为 0／200、高度 18／22／40，以及 1／2／5／20 行，同时检查单行不变和上下文无泄漏。CI 使用 271 字节初始化夹具，SHA-256 为 `172b31a07764174aa4b5697328f1e5ef742b5dc43cc4a394349dc8cee1ac45ee`；提供 EXE 时还核对夹具与受支持 EXE 一致，未安装游戏的 CI 不再跳过此项。

同一隐藏宿主已对旧实现实际运行负对照：0.3.33 因没有预留副文高度失败；0.3.34 在两行时因高度递增失败。候选通过。字体栅格化和最终游戏窗口仍不在这个宿主的证明范围内，必须继续实机检查原提示框、读档确认框、普通 NPC 气泡及日志，取得用户验收后才发布。

## 原因与修改

带颜色／图标的多行说明使用空注音锚点和独立副文。旧代码只补原生注音的高度和用户额外行距，未给普通副文预留完整高度；最终对齐将副文放到本行主文上方，却覆盖了上一行主文。

在已验证的原生解析结束入口读取子上下文的真实边界，将所需高度计入当前主行及测量边界。使用同一个入口处理绘制与测量；完整副文已包含原注音时不重复叠加。颜色、图标、字号由原解析器测量，不使用文字白名单、固定字号估算或新一次解析。
