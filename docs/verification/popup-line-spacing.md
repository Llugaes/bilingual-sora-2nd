# 多行提示框的双语行高

## 现场证据

2026-10-03，0.3.33、游戏 1.0.0.0，中主日副，主文比例 0.85、副文比例 0.9、上下间隔 0、额外行距 6。
用户重新打开“零力场生成器”说明后，以 `tools/read_native_layout.py` 只读采集到 layout 8 的 `root/text`。
原文和正式渲染结果都有五行；问题是相邻行重叠，而非遗漏换行字符。

| 后一行 | 上一行主文底边 | 本行副文顶边 | 重叠高度 |
|---|---:|---:|---:|
| 2 | 38.625 | 32.427 | 6.198 |
| 3 | 78.750 | 72.415 | 6.335 |
| 4 | 119.750 | 110.929 | 8.821 |
| 5 | 164.250 | 150.567 | 13.683 |

数值为控件本地坐标，包含阴影；最后一行还有图标。原始进程指针、配置和采集 JSON 仅保留在本机 generated，不进入发行包。

## 原因与修改

带颜色／图标的多行说明使用空注音锚点和独立副文。旧代码只补原生注音的高度和用户额外行距，未给普通副文预留完整高度；最终对齐将副文放到本行主文上方，却覆盖了上一行主文。

在已验证的原生解析结束入口读取子上下文的真实边界，将所需高度计入当前主行及测量边界。使用同一个入口处理绘制与测量；完整副文已包含原注音时不重复叠加。颜色、图标、字号由原解析器测量，不使用文字白名单、固定字号估算或新一次解析。

## 检查与边界

- `node --test --test-name-pattern='multiline formatted popup reserves' tests/test_native_agent.js`：修改前用现场坐标复现第二行重叠 6.198；修改后五行检查通过，覆盖测量／绘制及主语言、副语言、关闭效果恢复。
- 同文件的多行原注音回归验证主文原注音与副文完整高度各计算一次，重复重建不累加；既有单行、混排、强调字号和普通注音回归继续保留。
- `tests/check_native_nested_ruby.py --exe <GAME_EXE>`：独立隐藏宿主加载正式回调及真实注音初始化机器码，覆盖 18／22／40 高度的测量、绘制和单行不变；不附加游戏。该宿主的子解析是经过静态指令核对的字段夹具，不能替代完整游戏渲染。
- `python -m tools.dev check`：静态／格式检查通过；506 项 Python 检查通过（5 项环境相关跳过）、167 项 JavaScript 检查通过，Windows 隐藏原生宿主检查通过。含本地游戏 EXE 的嵌套注音检查已实际执行，未因 CI 缺少游戏资源而跳过。
