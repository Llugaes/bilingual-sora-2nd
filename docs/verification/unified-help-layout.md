## 现场与根因

r4 的回复药与装备均为 layout 33、`root/help/text`，同一原生控件。文字框 1300×130、anchor 8、Y=978；背景 `base` 为 2000×112、anchor 0、Y=926，因此背景贴图外框中心为 982，原生文字排版框中心为 978。

回复药最终字形原生投影中心为 976.758，装备为 982.165。r4 在资源正文准入后替换首行原点，无法让两条不同布局路径的最终范围一致，已撤回。新逻辑在排版完成后使用共同文字排版框与完整字形范围求居中偏移，不增加分类或语言分支。

现场与布局清单保存在工作树外的 `../unified-help-evidence/`。原生夹具中的旧字形仅作为最终投影阶段输入，不声称已经复现新版本完整字体解析或最终画面。

首个 r5 自测还发现：`camp001` 背景三段贴图的高度 112 包含顶部 5 个透明像素和底部渐淡阴影（主体 alpha 位于 `[5,102)`）。按其外框中心 982 对齐，会让回复药正文靠近可见灰底的下边。已拒绝该候选，改用游戏原生文字框中心；不增加资源／语言特例或像素补丁。alpha 分析、实际投影字形与失败画面保留在外部证据目录。
