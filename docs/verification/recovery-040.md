# 0.4.0 恢复版验证

0.3.34 的多行副文高度预留在实机造成窗口纵向异常扩张，普通对话也出现大间隔。现场只读采集发现五行提示框测量高度达 2137；原来的字段级检查不足以证明父窗口尺寸正确。0.3.35 保留了这个回归。

## 恢复范围

0.4.0 的游戏排版回到 0.3.33。`native_agent.js` 相对 0.3.33 唯一保留的差异是将全部入口指令校验移动到适配器工厂之前，避免校验把工具自己的原生钩子当作外部改写。撤回完整副文高度预留，不在恢复版继续尝试新高度公式。此前少数提示框拥挤仍待后续候选解决。

## 已执行检查

- 新增恢复回归：多行、颜色、图标、不同布局标志、测量与绘制、多次重排，以及副文边界高度 18／240／2137。对 0.3.35 脚本运行失败：主文基线预期 100，实际 118；对恢复后的脚本通过。分别保留在本地 `generated/recovery-layout-red.log` 和 `generated/recovery-layout-green.log`。
- `python -m tools.dev check` 通过：516 项 Python 测试、JS 回归及隐藏原生宿主检查，包括真实启动前校验、测量、字号、书籍及控制生命周期。本机检查使用游戏 EXE 的磁盘机器码，不向运行中的游戏添加诊断钩子。
- 手动更新测试覆盖旧自动更新配置迁移为只检查、检查不下载安装、取消确认、确认期间新版本不能替换所选版本、游戏忙时不排队自动安装。
- 历史版本测试覆盖数值排序与分页、过滤草稿和预发布、双源合并与单源不可用、按来源与版本隔离元数据、确认后重新校验所选标签、不同运行依赖、回退保留配置、回退事务中关闭旧自动更新、安装中断后恢复旧文件和配置。
- 三种界面语言的更新窗口已用实际 Qt 渲染并检查，README 图示同步更新。

## 交付边界

上述代码回归与用户实机视觉验收分别记录。0.4.0 是用户明确授权的恢复版；CI 仍须通过便携 EXE 与安装器检查后才手动公开。后续所有正式版必须先交付本地候选，用户明确验收该候选后才能公开。CI 只生成 draft。

当前游戏进程持有旧原生代码，安装恢复版后需正常重新启动游戏。既有进程的截图不能充当恢复版效果证据。
