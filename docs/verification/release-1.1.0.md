# 1.1.0 正式包核对

2026-10-31。本轮按用户明确的自主修复、测试及发布授权执行。没有取得本候选的玩家实机验收；已有正式 1.0.4 的连接状态和隐藏宿主结果分别保留，不能代替 1.1.0 游戏画面验收。

产品提交与标签：`7238241553d72efe617154464f1da7129743a95a` / `v1.1.0`。[GitHub 构建](https://github.com/Llugaes/bilingual-sora-2nd/actions/runs/41157418951)通过，是唯一正式构建源。[GitHub 正式版](https://github.com/Llugaes/bilingual-sora-2nd/releases/tag/v1.1.0)和 [Gitee 镜像](https://gitee.com/Llugaes/bilingual-sora-2nd/releases/tag/v1.1.0)均已公开。

问题定位和本机连接结果见 [兼容与模型加载验证](compatibility-1.1.0.md)。原先的不兼容提示未复现；本版修复的是另行复现的模型加载阻塞，未放松原生兼容合同。

## 成品与运行验证

- 五个 CI 附件实际下载完成后，逐一核对大小、GitHub API SHA-256 和更新清单。675 个受管文件与清单一致，应用源码及分发资源与产品提交一致；JSON 序列化和换行按构建规则核对。应用、运行依赖组件与完整包的文件集合及内容一致。
- 正式包 runtime ID 为 `48f971a5132306b6`。包内 Frida 扩展 SHA-256 为 `3b92871213c7610106c3a34987fa8b98dab0fa325c595251ed14920b5e5df30b`，依赖仍为 `17.18.0+sora.1`。
- 本地和产品 CI：861 项 Python（9 项条件跳过）、237 项 JavaScript、25 个原生检查入口及 Ruff 通过。
- 实际成品的 25 个原生入口最终全部退出 0。检查逐进程确认应用与 Frida 来自下载的包；固定旧 RVA 的独立机码检查使用保留原样本 `d8b2911d…4acf8aaf`，适应当前 EXE 的入口使用本机样本。首次检查器遗漏 `tests` 辅助模块路径，另有将当前 EXE 交给旧 RVA 检查、旧样本目录缺少资源视图的配置失败；修正检查器和隔离样本视图后通过，原失败收据保留，未改产品、削弱断言或改游戏文件。
- 当前 EXE 的生产兼容检查通过：13 个无关元数据、区段或诊断行号变化接受，8 个实际函数、参数、字段或架构破坏反例拒绝。只修改临时 PE 副本，未启动或附加游戏。
- 同一完整 wire 的成品加载回放通过：总加载 1.9720 s，最长保留事件 41.168 ms；全部回调累计分阶段峰值之和为 58.583 ms，低于原 100 ms 门槛，丢失计数为 0。这是保守上界，非单个回调的实测耗时或游戏帧率。复核发现环形事件可能淘汰加载早期记录，因此验证脚本另补累计峰值门禁和停止后的最终采样；该脚本不进入发行包，产品附件与标签未改。
- 原始 SCP 字节与完整模型回放：剩余 14 个调用对应 21 组输入、147 项检查通过，无哈希替身。
- 实际便携包通过无系统 Python、Unicode 路径、单实例、重载、模拟下一版组件更新、中断恢复和已加载 DLL 时更新检查。启动观察值 1.526 s。
- 隔离副本完成正式 1.0.4 → 1.1.0 组件与运行依赖升级，再回退至 1.0.4。每次核对全部受管文件；设置、非管理文件及旧运行依赖保留，回退后更新策略为 `off`。
- 同一安装器在 CI 通过离线安装、修复保留设置、运行中保护、开始菜单入口和卸载保留设置。本机复验因已有用户注册安装而按原保护规则停止，没有删除注册信息或覆盖现有安装，不计作本机安装器验收。
