## 验证结果

- CI：830 项 Python（9 项按条件跳过）、228 项 JavaScript 通过；隐藏原生宿主检查通过。
- 实际下载包：25 个原生检查入口均退出 0；需要另传游戏 EXE 的可选分支仍按条件跳过，没有冒充全部 EXE 验证。独立执行 40 万次回调，预热后 30 万次净残留 6,144 bytes；完整原生检查中的再次执行为 7,152 bytes。
- 实际下载包：无系统 Python、Unicode 路径、单实例、界面重载、模拟下一版组件更新、中断恢复及加载 DLL 时的更新验证通过；全部在隔离目录进行，没有附加游戏。
- CI 实际安装器：离线安装、修复保留设置、运行中保护、开始菜单入口及卸载保留设置通过。本机不重复安装覆盖用户现有安装。
- 三语 README 各有 13 张图；保留历史游戏演示图并标明性质，三语设置截图从 1.0.2 的真实 Qt 界面离线生成。图片引用、文档链接和折叠区闭合检查通过。

本机补验最初直接用嵌入式 Python 运行开发测试，缺少测试辅助模块路径，字体检查在 `ModuleNotFoundError` 后的清理阶段等待，25 秒诊断复现确认了这条路径。为测试显式提供辅助模块路径和 Capstone 5.0.9 后，原测试通过；未修改测试断言或产品运行时。每个检查均断言 Frida 和应用模块来自正式包。初次失败记录与修正后的完整日志同时保留。
