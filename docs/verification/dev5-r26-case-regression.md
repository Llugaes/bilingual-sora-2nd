## What changed

The four reviewed SetText callers provide the actual selected ItemTableData record in their preserved RBX/RDI registers. The compiler binds the complete category header plus description to that physical record and its selected ItemKindHelpData row. The runtime verifies the current owner/wrapper/table chain, selected descriptors, postload scalars and pointers, binary array, conversion sources, selected UTF-8 payloads, selector prefix and final copied input. It samples those dependencies twice and rejects observed changes. It does not promise atomic snapshots or every ABA detection.

The bounded constructor proof is independent of the existing direct-field full-pool proof. The old TableIdentities class is unchanged. A changed unrelated pool byte is permitted by the new selected-dependency contract; the old direct-field contract still requires its entire pool checksum. There is no item-ID or word whitelist, and no first-candidate winner.

Genuine rejection is source-only in primary, secondary and annotation modes, including the legacy dictionary branch. An explicit unsupported state can retain an independently valid old resolver. A proven record takes precedence over a conflicting global same-source pair. Copying a widget or reloading a model revokes this new identity; a copied constructor proof is not inherited. Destroy removes its domain. At 10000 distinct domains, a further domain stops bilingual rendering globally; callback leases are released, and a previously owned translation restores its saved raw source on the next normal Update.

An admitted header is explicitly single-line in the source and both selected target languages. The existing first-header clearance correction now receives the verified mode-zero boundary. Body baselines use the existing metrics. The user reported at 12:20 UTC on 2026-10-07 that the r25 descriptions and line breaks they observed were correct, with Tools type/range as the remaining visible issue. This observation does not certify every offline row. Geometry is frozen for the Tools follow-up.
