## 验证结果

- 本地与 CI 最终代码检查通过：844 项 Python（9 项条件跳过）、232 项 JavaScript、25 个隐藏原生宿主检查及 Ruff。
- 实际 CI 包的 25 个隐藏原生检查均退出 0。40 万次回调的净残留为 6,096 bytes，原泄漏门槛通过。需要游戏 EXE 的可选分支仍按条件跳过。
- 实际便携包通过 Unicode 路径、无系统 Python、单实例、重载、模拟下一版组件更新、中断恢复和已加载 DLL 时更新检查；启动观察值为 0.872 秒，不代表游戏帧率。
- 隔离副本实际执行正式 1.0.2 → 1.0.3 组件升级，再回退至 1.0.2。管理文件全部校验通过，设置、非管理文件及旧依赖保留；回退关闭自动更新。
- CI 实际安装器通过离线安装、修复保留设置、运行中保护、开始菜单入口及卸载保留设置。本机没有覆盖用户现有安装。
- 正式包从本机游戏资源首次生成完整词库通过，用时 179.09 秒。984,810 条目录、269,850,619 字节运行模型和 173,779,360 字节 indexed wire 均与已审计最终模型逐字节一致；因此前述资源与回放证据适用于实际发行包生成物。此处只核验成品建库，不替代同机顺序性能对照。

首次成品建库检查的临时脚本遗漏 Windows 多进程入口保护，子进程重入并等待准备锁。进程树和调用入口确认原因后，只终止本次验证进程并修正脚本；产品入口原本已有保护，没有修改产品或放宽断言。修正后完整建库及生成物摘要核对通过，初次失败及重跑记录均保留。
