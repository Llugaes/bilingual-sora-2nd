# 游戏过程中的主动语音框下移

## 范围和状态

2026-09-29 用户要求只将游戏过程中的主动语音框文本稍微下移，普通剧情框正文整体下移仍取消。
当前为本地候选代码，未在用户正在运行的游戏中安装，未获得实际画面验收，也未发布。

## 分类依据

截图“不过，你也别那么灰心。／这不正是接近男朋友的突破口吗？”来自
`t_active_voice.tbl/group:79/sequence:990542ccfa05b165bdff43ee06f210da314c7301c01ec18f2c04d524381e3c27/record:1/body`。

已验证 EXE SHA-256：`d8b2911d1576216bdc22d070550e4f531e105de7ed2981885849669f4acf8aaf`。
`0x26402` 设置 layout ID `0x20`，`0x26414` 调用布局创建；随后选择 `items/item`。
其控制器构造器 `0x25a20` 在 `0x25b29..0x25b49` 找到并保留 `text` 控件。
外部只读采集 `generated/diagnostic-147-layout.json` 同时观测到布局 32 的
`root/items/item/text` 和普通剧情布局 7 的 `root/text`，二者不是同一个表面。
采集时已推进到其他对白，故不能把该采集写成截图原句的实机修复验证。

## 实现

仅布局 32、`items/item/text` 且确有双语副文的控件获得 8 个布局单位的下移。
在已有标签 Update 投影边界与日志共用 `projectTextInset`，沿父节点 Y 轴移动标签矩阵，
Update 返回前共用 `restoreTextProjection` 恢复。不移动背景、头像或主副语言的内部相对位置。
布局退休或根节点被其他布局复用后，原分类不再授权偏移。单语、关闭效果、普通剧情及 NPC 气泡不增加此偏移。
无需新增逐字遍历；分类沿既有文本接管时的祖先读取完成，投影只做集合检查和固定数量矩阵读取。

## 检查

- 新回归在修改前以 `400 != 416` 失败；父节点放大 2 倍时，8 个布局单位应对应 16 个投影单位。
- `tests/test_native_agent.js` 覆盖布局 32/7/8/0、正文/姓名、逐帧重复、模式切换、关闭效果及布局复用。
- `tests/check_native_log_inset.py` 在自行创建的隐藏宿主中执行当前 EXE 的投影矩阵运算，
  同时调用生产偏移/恢复函数；主动语音和原有日志断言通过，未附加或启动游戏。
- 真实屏幕位置和框底余量仍待新进程加载候选后验收。截图表明需要小幅移动，不能由宿主测试替代视觉确认。
