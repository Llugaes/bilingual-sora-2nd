# 全书重排与原生阅读器验证

2026-10-03，用户确认本轮纳入整本重排。不同语言的物理页号不再作为正文配对键。

## 资源与显示合同

八语 `BooksText` 均有 83 个章节。日／简中／繁中／韩各 367 页，英 425、法 442、德 446、西 421 页。
每行 24 字节：章节 ID 位于 `+0`，页号 `+2`，正文指针 `+8`，插图指针 `+16`。
同一章节必须具有连续页号与相同的有序插图序列；不满足时保留审计缺项，不猜配到相邻章节。

`table_alignment.py` 保留每语全部原页，按章节 ID 建立完整文档。普通菜单词典和表指针模型
不接管这些正文，以免再次按相同页号配错。`RuntimeBooks` 从完整主副文生成共同分页，主语言
决定插图边界。双方按整章阅读进度分配文本，保留全部行和空行；**不声称每个句子、段落都逐一对齐**。
书籍没有原生跨语句子 ID，插图边界也不能证明句子对应。

双语分页预算来自原始 `note_books.lay` 的正文高度 680、字号 30，并预留主副注音和用户行距。
只在打开章节或显示设置改变时计算并缓存，普通移动、战斗帧不遍历书籍。
单语言使用该目标语言原分页；关闭 MOD 恢复游戏来源语言原页。

## 原生边界

| 入口 | 已核对行为 |
| --- | --- |
| `0x23c1e0` | 按章节返回最大页号；所有已读资源页号连续 |
| `0x23c270` | 按章节、页号返回原始记录或空指针 |
| `0x4079c0` | 更新阅读器当前页；正文经 `0x407d80` 调用 SetText |
| `0x407444` | 图片查询；复制记录 `+16` 的插图名称 |
| `0x406c6b` | 初次打开时，将原始书签页转换为对应重排页 |
| `0x40715a` | 保存书签前，把显示页转换回原始物理页；不改变当前显示页 |

`native_books.js` 只替换阅读器调用的页数和页面查询结果，返回自有记录与字符串，不改游戏表文件。
正文仅在验证过的 SetText 返回地址 `0x407d85` 绑定书籍身份。每次模式／模型改变按原生更新函数
刷新当前书页；稳定帧不重复刷新。关闭双语时同时恢复页数、正文与合法原页码。
原生书签只存一个字节，因此重排上限为 255 页，超过时不截断正文或回绕页码。

## 验证

- `check_book_documents.py` 独立读取八语原表、布局及最终目录：512 组语言配置、42,496 个文档组合、
  1,244,632 个分页结果、7,101 个最终渲染案例通过；最大 45 页。检查全文不丢失、不重复、不乱序，
  插图顺序、逐页注音闭合、行数预算，以及单语言保留原分页。
- `check_native_books.py` 读取实际 EXE 的指令与调用点，将**实际页查询机器码**复制到自建隐藏进程，
  在合成表上运行正式适配器。2 原页扩展为 16 页，逐页正文、页数、插图、关闭恢复、原书签保存／恢复、
  模式切换及稳定帧不重复刷新通过。CI 无游戏 EXE 时使用同布局 C fixture，报告明确区分两种证据。
- `test_runtime_books.js` 覆盖文档配对、页数上限、错误来源及插图序列不一致等边界。

以上没有启动或附加玩家游戏，不能替代实际阅读器的视觉验收，尤其是字体、页边缘与翻页动画。
本地完整原文及报告留在 `generated/todo-book-*.json`，不随仓库或安装包分发。
