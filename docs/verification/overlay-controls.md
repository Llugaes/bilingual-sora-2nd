## Windows 原生窗口检查

独立离线 Qt 宿主使用临时配置，不连接或启动游戏。读取真实窗口样式并使用另一个普通窗口遮挡：取消 Pin 时两个窗口均无 `WS_EX_TOPMOST`，覆盖窗口可命中；启用 Pin 后恢复最前方。

在 0%、50%、100% 背景透明度下，背景像素 alpha 分别为 255、128、1；前景仍包含 alpha 255。全透明状态下 Windows `WindowFromPoint` 仍命中悬浮条，保证空白区可操作。alpha 1 是为 Windows 分层窗口保留的命中区域。隐藏、刷新、再从托盘恢复均通过，游戏控制文件保持不变。

证据：`generated/overlay-0326-native.log`、`generated/overlay-opacity-0326.png`。原生桌面检查不等价于独占全屏游戏覆盖验证；没有启动游戏进行该项实测。
