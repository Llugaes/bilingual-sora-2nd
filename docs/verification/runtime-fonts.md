# 游戏运行期间加载多语言字体

## 交付状态

2026-09-29：0.3.24 补齐已有 HUD 控件的材质图集刷新，详见 [字体、性能与地图地点检查](hud-performance-and-map.md)。下文保留最初字体加载方案的实现与验证记录。
目标是首次使用时即使先启动游戏，也能在字体准备完毕后直接启用双语。
字体资源与映射首次生成仍允许等待；有效缓存必须复用。
真实 GPU 上传、首次加载时画面、继续游玩、语言切换和退出恢复仍待实机验收。
隐藏宿主检查不等于这些实机结论。

## 实现边界

- `fonts/runtime_fonts.py` 校验四套 FNT/DDS，按原始 FNT 内容摘要匹配实际 face；不根据语言设置猜测。
- `runtime_fonts.js` 管理准备、发布、恢复与有界缓存。重复准备共用一次未完成请求；失败不发布半套字体。
- `native_fonts.js` 使用游戏自己的分配器、FNT 读取器和图片缓存。来源身份在 Update 取得；新资源读取和上传由事件循环执行，Update 只发布完整 face。
- image-cache 的 CALL 使用 C 回调替换本工具独立贴图名称的路径；不会拦截全局文件读取函数。Frida 负责安装和指令迁移，不自行并发改写五字节 CALL。
- 图集、字库及 face 作为整体保留。退出在下一次 Update 恢复原 face，游戏 reset 前恢复引擎拥有的原对象。有界缓存最多四套准备结果，重新启用不重复上传。
- font generation 使已跟踪文字（包括未翻译原文）重新生成字形，保留动画进度。无变化的后续帧不重复重建，也不反复读取字体文件或计算摘要。
- 游戏目录在运行期间不写入。未运行时继续原有可回滚安装流程。UI 和后端使用同一跨进程构建锁，避免双重构建。

## 原生证据

目标 EXE SHA-256：`d8b2911d1576216bdc22d070550e4f531e105de7ed2981885849669f4acf8aaf`。

| 入口 / 字段 | RVA / 偏移 | 核对内容 |
|---|---|---|
| FNT 读取 | `0x5BFA10` | 参数为未使用 manager、目标 face、文件路径；返回 0 成功 |
| 字体分配 | `0x5CA0C0` | 使用全局分配器 `0xC60E78` 的 `+8`；入口内部加锁 |
| 图集获取 | `0x38AE0` | image-cache 全局 `0xC60EF0`；入口内部加锁，禁止绘制线程禁入区调用 |
| 图片文件读取 CALL | `0x5C6103` | 目标 `0x654640`，保留其他参数与原读取器 |
| font manager | `0xC60ED0` | `+8` face 向量、`+0x10` 数量；当前已验证数量为 1 |
| font face | `+0/+8/+0x10/+0x18/+0x20/+0x28` | 分配、FNT、字形表、查找步长、图集、引擎字号 |
| 图集完成 | image `+8` resource，resource `+0x64` | 完成标记 1；另核对类型及 image `+0x1c/+0x20` 宽高 |
| reset / load | `0x5BF8F0 / 0x5BF350` | reset 回收原有 face；临时失败对象使用相同原生回收路径 |

实际只读采集的引擎字号为 48，FNT 头名义字号为 68。保留 `face+0x28`，不可用 FNT 头覆盖。
磁盘路径规范化 `0x5B2170` 保留路径并将反斜线改为斜线；文件读取器使用 512 字节路径缓冲，候选明确限制 UTF-8 路径长度。

## 检查

- `node --test tests/test_runtime_fonts.js`：完整准备后发布、退出/迟到结果、reset 后复用、失败保留原字库、并发请求合并。
- `tests/check_native_fonts.py --exe ...`：核对实际 CALL 和 FNT 描述符指令；隐藏原生宿主检查路径隔离、五参数和 64 位返回值、禁止重复安装。调用全局读取器不会走本工具的重定向。
- 同一隐藏宿主加载完整生产适配器，使用真实文件读取/CNG 摘要和夹具引擎资源，检查 staging 不发生于 Update、一次上传后复用、下一次 Update 恢复原 face、未知字库拒绝覆盖、图集失败清理。
- `tests/check_native_refresh.py`：执行生产 Update 回调，新增“原文不变但字库已变化”检查，重测和重绘一次，下一帧不重复。
- `tests/test_runtime_fonts.py`：四套清单只读小型源 FNT 档案、字体阶段不会误报已就绪、两个独立进程只构建一次。
- `tests/test_font_delivery.py`：游戏已运行及验证期间启动时，均保留游戏目录不写入，返回运行时加载状态。

本机已有有效缓存时，准备运行时清单耗时约 0.61 秒。该数字不代表首次构建、首次 GPU 上传或端到端双语就绪时间。

代码回归：全量 Python 419 项（5 项跳过）、JS 160 项及可运行的隐藏原生检查通过；依赖 EXE 的字体、字号和嵌套注解检查另显式传入已校验 EXE 执行通过。没有把默认跳过项计为通过。
候选 ZIP 内 91 个源文件逐字节与工作区核对一致（发行版本元数据及被便携包移除的脚本入口不计入），确认包含三个新增字体模块，不包含本地生成状态或游戏字库。
