# 放大对白的副语言字号

2026-09-29：代码回归通过，加入 0.3.18 本地开发候选；新候选画面尚未实机验收。

## 原始证据

用户停留的“凯诺娜／……吵死了，闭嘴！”来自普通剧情布局 7 的 `root/text`。
只读采集耗时 339 ms，取得 4 个相关标签，读取错误为 0；未向游戏写入数据。
正文原串为 `<R></R_><#L[1#107w7]#G[6]#M_2#B_0#S[1]><S5>……吵死了，闭嘴！`。
实际资源中的日文也含 `<S5>`，不存在译文丢失字号指令的问题。

标签字号 33，引擎字体基准 48，实际 S5 正文等效字号 37；用户主文比例 .85、副文比例 .9。
采集的同字符省略号字形宽度为主文 27.518749、副文 13.509205。
现有 S/s 修正已按实际基准换算，但最终 `finishAnnotationLanes` 又给副文乘了 .85。
普通文本的主文前置 `<s>` 路径没有这次副文缩小，因而放大对白的副文反而可能比普通副文更小。

原始本地证据为 `generated/diagnostic-150-enlarged-dialogue.json`，不包含在分发包中。

## 修改与核对

- 保留共用字号解析、资源指令和用户副文比例，移除最终字形阶段的副文二次缩小；没有按句子、人物、布局编号或放大档位分支。
- 最终几何缩放只处理主文。主文原注解和副文原注解仍分别预留高度，包括首行；副文注解随副文自己的解析倍率显示。
- 新回归串联生产字号上下文、独立副文登记和最终字形处理。216 组组合包含 4 种标签字号、3 种字体基准、8 种绝对字号及采集的 S5、静态和逐字显示；同一字形比较尺寸，重复帧检查不累乘。修改前失败，修改后通过。
- 既有颜色、嵌套注解、首行行高、图标、非零前缀、连续重排和日志测试继续通过。
- `tests/check_native_size_metrics.py --exe ...` 在自建隐藏宿主执行已校验 EXE 的 S/s 算术和生产修正，结果通过；没有附加当前游戏。
- 全量检查为 Python 419 项（5 项跳过）、JS 160 项通过。依赖 EXE 的字号检查另显式传入 EXE 执行，不能把默认跳过当成通过。

这些检查证明代码路径及算术，不等同于新的游戏画面验收。当前游戏保持旧驻留代码，不能热替换；不要求用户再次保留每一种放大对白。
