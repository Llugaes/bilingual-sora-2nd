# Bilingual Sora 2nd — 空の軌跡 the 2nd 二言語字幕 Mod

[简体中文](README.md) · [English](README.en.md) · **日本語**

**Trails in the Sky the 2nd bilingual subtitles mod · 空之轨迹 the 2nd 双语字幕 Mod**

PC 版『空の軌跡 the 2nd』の二言語表示 Mod。会話やメニューを同時に見比べたり、ショートカットを押している間だけ言語を切り替えたりできます。主言語と副言語は、日本語・英語・簡体字中国語・繁体字中国語・韓国語・フランス語・ドイツ語・スペイン語から選べます。

現在の対応バージョンは Steam build **25386012**、EXE **1.03.2** です。フックの適用前にゲームのバージョンを検証し、未対応版へ強制適用しません。元の PAC / EXE ファイルは書き換えません。開発初期のプロジェクトであり、オフライン回帰テストと一部の実機確認を行っていますが、ゲーム全体の網羅性、各言語のレイアウト、コントローラーの互換性には引き続き実機での確認が必要です。

**普段のプレイには、単言語表示＋押している間だけ副言語への切り替えを推奨します。** 通常は主言語を読み、比較したいときだけショートカットを押し、離すと戻ります。二言語同時表示も利用できますが、会話履歴を開く際の一時停止やフレームレート低下が残っています。詳細は下記をご覧ください。この推奨により既存の設定が変更されることはありません。

## インストール

1. [最新の Release](https://github.com/Llugaes/bilingual-sora-2nd/releases/latest) から `bilingual-sora-2nd-VERSION-windows-x64-setup.exe` をダウンロードし、実行してインストールします。
2. スタートメニューまたはデスクトップのショートカットから **Bilingual Sora 2nd** を開き、初回は画面の言語を選択します。主言語は新しいゲームプロセスへの接続時に同期され、その後は主言語・副言語を変更できます。
3. ツールがゲームを自動検出し、多言語フォントを準備します。フォルダーやゲーム言語の選択は不要です。準備前にゲームを起動しても、完了後にゲーム内へ読み込みます。初回の言語マッピングには数分かかる場合があり、有効なキャッシュは再利用します。

Windows 10/11 x64 対応、管理者権限は不要です。Python と依存ライブラリは同梱されているため、ダウンロード後はオフラインでインストールでき、別途環境を用意する必要はありません。画面は日本語・英語・簡体字中国語に対応し、更新時も既存の設定を保持します。

ポータブル版、旧版からの移行、問題の対処は下記の [よくある質問](#よくある質問faq) をご覧ください。

見出しの「···」メニューから使い方とリリースノートを開けます。再度起動すると既存の画面が開き、バックグラウンド処理は重複しません。

ゲームの手帳素材を使い、設定を「言語と表示」「文字レイアウト」「クイック操作」「ツールの外観」に分類しています。更新は見出しの専用ボタンから開きます。主言語・副言語は自由に組み合わせられます。「ゲーム内の表示言語」は検出結果を表示する読み取り専用の項目です。接続失敗時は自動で再試行し、「言語と表示」タブの接続ボタンから手動で再試行することもできます。Mod の主言語は表示する本文だけを変え、ゲーム設定を書き換えません。

### 初回の言語設定

主言語の初期値はゲームの表示言語と同じです。副言語は日本語、ゲームが日本語の場合は英語になります。

ゲームを新しく起動するたびに、実際の表示言語を主言語へ一度だけ同期します。その後は自由に変更でき、同じゲームプロセスへの再接続では上書きしません。副言語とその他の設定は再起動・更新後も保持します。画面の言語は初回に日本語・英語・簡体字中国語から選び、「ツールの外観」の「画面の言語」で変更できます。「言語と表示」タブは有効化スイッチを最上部に、主言語と副言語を横並びに配置します。閉じたドロップダウン上でホイールを回しても選択は変わりません。

Steam のゲームフォルダーを自動検索します。初回起動後に実際のテキスト言語を検出し、手元のリソースから言語キャッシュを自動作成します。有効なキャッシュは再利用し、ゲーム設定は変更しません。テキスト描画にはゲーム本来の表示機能を使い、Qt の画面は設定と状態表示を担当します。ウィンドウまたはボーダーレス表示を利用してください。排他的フルスクリーンでは設定画面が表示されない場合があります。

### 多言語フォント

言語の組み合わせによっては、元のフォントにない文字が「?」になるため、拡張フォントが必要です。手元のゲームリソースから自動で準備し、ゲーム終了中は導入、起動中は字形情報と画像をメモリーへ読み込みます。フォント準備のためのゲーム再起動は不要です。準備・読み込み・完了・失敗は個別に表示します。ゲームフォントは配布せず、OFL ライセンスの補助字形を二つ同梱しています。

機種に合わせてボタン名を表示します。PlayStation は L1/R1・L2/R2・L3/R3、Xbox は LB/RB・LT/RT・LS/RS（押し込み）、Nintendo Switch は L/R・ZL/ZR・スティック押し込みです。フェイスボタン・方向キー・スティックの方向もデバイスの対応表に従います。Steam Input 経由で Xbox と認識される場合は「コントローラーのボタン名」で表示形式を選べます。割り当て自体は変わりません。新しく登録したボタン名は切断後も保持されます。既存の割り当ては該当するコントローラーを接続すると判別できます。SDL の対応表にない入力は元の番号で表示します。

- **二言語モード**：ゲーム本来のルビ機能で二言語を同時表示します。ショートカットで副言語の表示を切り替えます。
- **単一言語モード**：「押して切り替え」または「押している間だけ副言語」を選びます。押し続けても再切り替えせず、後者は離すかゲームが前面でなくなると主言語に戻ります。

文字サイズと間隔は即時反映され、メニューを開き直しても維持します。副言語の色は元の RGB に係数を掛け、初期値は RGB 230 / 230 / 230、不透明度 90% です。色ボタンの下のスライダーで不透明度を調整できます。上下移動は二言語モードのみ有効で、正の値は下方向です。

初回接続時やゲームリソースの変更後には言語キャッシュを自動準備します。数分かかる場合がありますが、有効なキャッシュは再利用します。

## 推奨設定と既知の制限

快適さを優先する場合は **単言語モード → 押している間だけ副言語**を選び、押しやすいキーボードまたはコントローラーの組み合わせを登録してください。普段は主言語だけを表示し、比較するときに押し、離すと戻ります。二言語を常時同時に組版しないため、現在の日常利用向けの推奨設定です。切り替え時には短い再レイアウトが発生する場合があり、遅延が完全になくなるとは限りません。

- **二言語の会話履歴には、未解消の性能上の制限があります。** 開く際に一瞬止まったり、表示中のフレームレートが単言語より低下したりする場合があります。実機では約 **700 ms** の停止が報告されており、開き直した場合にも発生します。履歴量、言語の組み合わせ、機器によって変わります。キャッシュとネイティブ処理の最適化で一部の負荷は軽減されていますが、解消済みではありません。気になる場合は上記の単言語・長押し切り替えで履歴を閲覧してください。
- **負荷はフォント描画だけでなく、レイアウトと解析にもあります。** 二言語表示はゲーム本来のルビ機能を利用します。履歴をまとめて処理し、表示中も一部のテキストを繰り返し解析するため、副言語の色や不透明度を変えてもこの処理は省略されません。
- **言語ペアの初回準備には時間がかかります。** 初回接続、未キャッシュの組み合わせ、ゲームリソースの変更時にはローカルリソースの処理が必要です。初期化は自動で進み、完了すると副言語が表示されます。これは履歴を開く際の停止とは別の処理です。
- **対応範囲と表示領域には限界があります。** 対応関係が不明な文章は原文を保持し、画像・動画に埋め込まれた文字は処理しません。二言語表示によって固定テキスト枠が広がるわけではないため、長文や大きな文字では窮屈になる場合があります。文字を小さくするか、単言語モードを利用してください。ゲーム全体とすべての言語ペアの検証は完了していません。

## 自動更新

見出しの「更新」パネルの **自動更新** は初期値でオンです。起動時と六時間ごとに安定版を確認し、バックグラウンドで取得・検証して、ゲームとの接続終了後に適用します。設定・キャッシュ・ウィンドウの状態を保持して画面を再読み込みします。オフでも手動確認は利用できます。 新版があるとボタンが金色になり、赤い点が付きます。バーの歯車にも赤い点を表示し、パネルを開いても通知は消えません。

## よくある質問（FAQ）

<details>
<summary>ツールを終了したのに、インストーラーが実行中と表示するのはなぜ？</summary>

0.3.15 以前では接続がゲームの終了まで残るため、インストーラーが実行中と判定する場合があります。ゲームをセーブして終了し、トレイからツールも終了してから再試行してください。

0.3.16 からは、トレイの「ツールを終了」で二言語表示を無効にし、画面・バックエンド・準備用の全プロセスが終了してからアイコンを消します。ゲームはそのまま続けられ、ツールを開き直すと二言語表示を再開できます。画面の折り畳み・非表示では接続を維持します。旧版で接続済みの場合は、一度ゲームを通常終了してから新しい終了方式を利用できます。

</details>

<details>
<summary>ポータブル版の使い方と、Release 内の他のファイルの用途は？</summary>

名前に `app`・`runtime` を含まない完全版 `bilingual-sora-2nd-VERSION-windows-x64.zip` をダウンロードし、書き込み可能な独立したフォルダーへ展開して **BilingualSora2nd.exe** を開きます。EXE だけを移動せず、フォルダー全体を保持してください。

`app`・`runtime` ZIP と `bilingual-sora-2nd-update.json` は自動更新用、GitHub の Source code は開発者用です。更新機能は変更のない実行環境を再利用し、途中のバージョンは飛ばせます。

</details>

<details>
<summary>旧版の更新失敗や「更新包文件过多」にはどう対処しますか？</summary>

**0.2.x** からは一度だけ手動移行が必要です。旧更新機能は同梱ランタイムを扱えません。旧ツールを終了し、新しいフォルダーに展開して、旧 **generated/native-control.json** と **generated/overlay-window.ini** をコピーしてください（**.venv/**、**generated/updates/**、旧ホットリロード情報はコピーしません）。新 EXE の起動後はプログラムと依存ライブラリの自動更新が可能です。ソースの作業フォルダーとは分けてください。

0.2.2 の「更新包文件过多」（ファイル数が多すぎます）も旧更新機能の制限です。上記の手順で移行してください。0.3.0–0.3.3 からは一度だけ完全版による自動更新を行い、その後はコンポーネント更新を利用します。

</details>

<details>
<summary>再インストール・アンインストールの方法は？</summary>

再インストール・削除の前にトレイからツールを終了し、ゲームとの接続を終了してください。最新版のインストーラーで上書きインストールでき、Windows の「インストールされているアプリ」から削除できます。個人設定は保持し、ゲームを強制終了しません。

</details>

<details>
<summary>フォントの自動準備に失敗した場合は？</summary>

通常は手動操作は不要です。自動準備に失敗した場合の調査または再試行に限り、次のコマンドを使います。

```powershell
$runtime = Get-Content runtime/current.txt
& ".\runtime\$runtime\python.exe" -m sora_bilingual.fonts.install_font_patch --game "ゲームのインストール先" --install
```

インストーラーには監査済みの [sora2looseload](https://github.com/lmaple0/sora2looseload) ローダー（SHA-256 **e08a18068a482bb5d187a62023759c0e14ab69d76395b773ef0405d35e2ac8c7**）が含まれます。不一致の検証を無効化せず、他の Mod が所有するファイルは上書きしません。

</details>

<details>
<summary>自動更新の失敗から復旧するには？設定はどこに保存されますか？</summary>

更新に失敗した場合、「更新」パネルのダウンロードとログのボタンを利用してください。最新版のセットアップ EXE で再インストールできます。

更新パッケージはバックグラウンドで取得し、リポジトリ、バージョン、ファイル一覧、SHA-256 を検証します。ゲームに接続している間は適用を待ち、接続終了後にインストールします。画面は自動で再読み込みされ、位置と展開・非表示状態を復元します。設定とキャッシュは **generated/**、依存ライブラリは **runtime/** に保持します。更新が中断された場合、次のショートカット起動時に適用を完了するか旧ファイルへ復元します。バックアップは **generated/updates/backup-*** にあります。

自動インストールは **installed-manifest.json** を含む配布版が対象です。Git の開発フォルダーや、手動変更されたソフトウェアファイルは上書きしません。ランタイム更新は別のバージョン用フォルダーに適用し、画面の再読み込み時に切り替えます。使用中の DLL は上書きしません。旧ランタイムは復旧用に残り、追加のディスク容量を使用します。ドラフト、プレリリース、旧バージョンは自動導入しません。

</details>

## 開発とコントリビュート

<details>
<summary>開発環境・テスト・リリースのコマンド</summary>

```powershell
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[dev]"
.venv\Scripts\python.exe -m tools.dev check
```

**tests/check_overlay_update.py** は独立した設定で Qt 画面の再読み込みを検証し、ゲームには接続しません。**tests/check_native_transport.py** はローカルのリソースを必要とし、自分で生成したテスト用プロセスだけに接続します。これらはゲーム不要の CI 単体テストとは別の統合テストです。

開発中の変更は **python -m tools.dev publish-local** で構文検証後にアトミックに公開できます。画面とテキスト処理はホットリロードし、常駐フックの変更は次回のゲーム起動を待ちます。ゲームの実行中に注入済みスクリプトを強制終了・アンロードしないでください。

[アーキテクチャ](https://github.com/Llugaes/bilingual-sora-2nd/blob/main/docs/ARCHITECTURE.md)と[貢献ガイド](https://github.com/Llugaes/bilingual-sora-2nd/blob/main/CONTRIBUTING.md)は現在中国語です。Issue・Pull Request を歓迎します。不具合報告にはツールとゲームのバージョン、言語の組み合わせ、再現手順、必要最小限のエラー情報を添えてください。ゲームデータ全体はアップロードしないでください。

公開時は **distribution.json** と **pyproject.toml** のバージョンを揃え、対応する **vX.Y.Z** タグを push します。GitHub Actions が Windows 上で検証し、明示したファイル一覧から完全版 ZIP、更新用コンポーネント、オフラインインストーラーを生成します。ポータブル版の起動とインストーラーの検証後、すべての配布ファイルをドラフトへアップロードし、まとめて公開します。手動ビルド：

```powershell
$distribution = Get-Content distribution.json | ConvertFrom-Json
.venv\Scripts\python.exe -m tools.build_portable --version $distribution.version --repository $distribution.repository
```

リポジトリの説明文には選定した表示例の画像を含みますが、配布パッケージには同梱しません。ゲームのリソースアーカイブ、生成したゲームフォント、完全なテキスト索引、ログ、ユーザー設定は、いずれにも含めません。
