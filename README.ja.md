# Bilingual Sora 2nd — 空の軌跡 the 2nd 二言語字幕 Mod

[简体中文](README.md) · [English](README.en.md) · **日本語**

**Trails in the Sky the 2nd bilingual subtitles mod · 空之轨迹 the 2nd 双语字幕 Mod**

会話字幕やメニューで日英・日中などの対訳を表示。押している間だけの言語切り替え、トグル切り替え、ルビ形式の二言語注釈で語学学習をサポートします。

PC 版『空の軌跡 the 2nd』のゲーム内テキストを二言語で表示する Mod です。主言語と副言語は、日本語・英語・簡体字中国語・繁体字中国語・韓国語・フランス語・ドイツ語・スペイン語から自由に組み合わせられます。日本語でプレイする場合、初回設定では日本語の本文を保ち、英語を小さな注釈として添えます。原文との比較や語学学習に利用できます。

現在の対応バージョンは Steam build **25386012**、EXE **1.03.2** です。フックの適用前にゲームのバージョンを検証し、未対応版へ強制適用しません。元の PAC / EXE ファイルは書き換えません。開発初期のプロジェクトであり、オフライン回帰テストと一部の実機確認を行っていますが、ゲーム全体の網羅性、各言語のレイアウト、コントローラーの互換性には引き続き実機での確認が必要です。

**普段のプレイには、単言語表示＋押している間だけ副言語への切り替えを推奨します。** 通常は主言語を読み、比較したいときだけショートカットを押し、離すと戻ります。二言語同時表示も利用できますが、会話履歴を開く際の一時停止やフレームレート低下が残っています。詳細は下記をご覧ください。この推奨により既存の設定が変更されることはありません。

## インストール

**推奨：インストーラー版。** [Releases](https://github.com/Llugaes/bilingual-sora-2nd/releases/latest) の `bilingual-sora-2nd-VERSION-windows-x64-setup.exe` を実行してください。日本語・英語・中国語のウィザードで管理者権限なしに現在のユーザー用フォルダーへインストールし、スタートメニューと任意のデスクトップショートカットを作成します。依存関係は同梱されており、オフラインでインストールできます。Windows の「インストールされているアプリ」から削除しても設定を保持します。再インストール・削除の前にトレイから終了してゲームとの接続を終了してください。ゲームは強制終了しません。

**ポータブル版：** 自分でフォルダーを管理する場合は以下の ZIP 手順を利用してください。

**0.3.4** 以降は依存関係が同じなら小さなプログラム部分だけを取得します。実行環境は必要な場合だけ取得し、途中のバージョンは飛ばせます。0.3.0–0.3.3 からは一度だけ完全版による自動更新が必要です。`app`・`runtime` ZIP は更新用です。手動インストールではインストーラーか完全版 ZIP を選択してください。

**0.2.2 の「更新包文件过多」（ファイル数が多すぎます）は旧更新器の制限です。** 再試行せず、インストーラーと以下の設定移行手順を利用してください。新更新器は失敗時にダウンロード入口を表示し、詳細はログに記録します。

1. [Releases](https://github.com/Llugaes/bilingual-sora-2nd/releases/latest) から **bilingual-sora-2nd-VERSION-windows-x64.zip** をダウンロードし、書き込み可能なフォルダーに全体を展開します。
2. **BilingualSora2nd.exe** をダブルクリックします。Python と必要なライブラリは同梱済みです。Python のインストール、CMD の実行、初回の依存ライブラリ取得は不要です。Windows 10/11 x64 対応。
3. 初回はツールの画面言語を選びます。ゲームの原文言語は接続後に自動検出します。起動中のゲームへ自動接続し、未起動の場合は待機します。ツール自体はゲームを起動しません。

更新タブから使い方とリリースノートを開けます。更新に失敗した場合はダウンロードとログのボタンが表示されます。EXE を再実行すると既存の画面が開き、バックグラウンド処理は重複しません。画面は日本語・英語・簡体字中国語に対応します。

必要なのは ZIP のみです。**bilingual-sora-2nd-update.json** は自動更新用、GitHub の Source code は開発者用です。EXE だけを移動せず、展開したフォルダー全体を保持してください。

**0.2.x** からは一度だけ手動移行が必要です。旧更新機能は同梱ランタイムを扱えません。旧ツールを終了し、新しいフォルダーに展開して、旧 **generated/native-control.json** と **generated/overlay-window.ini** をコピーしてください（**.venv/**、**generated/updates/**、旧ホットリロード情報はコピーしません）。新 EXE の起動後はプログラムと依存ライブラリの自動更新が可能です。ソースの作業フォルダーとは分けてください。

設定は「言語」「文字レイアウト」「ショートカット」「更新」に分かれています。主言語・副言語は自由に組み合わせられます。「ゲーム内の表示言語」は検出結果を表示する読み取り専用の項目です。接続失敗時は自動で再試行し、言語タブの接続ボタンから手動で再試行することもできます。Mod の主言語は表示する本文だけを変え、ゲーム設定を書き換えません。

### 初回の言語設定

主言語の初期値はゲームの表示言語と同じです。副言語は日本語、ゲームが日本語の場合は英語になります。

これは初期値であり、言語の組み合わせを制限するものではありません。既存の設定は再起動や更新でリセットされません。画面は日本語・英語・簡体字中国語に対応し、初回に選択します。「画面の言語」で即時切り替えやシステム言語への追従ができます。画面の言語、照合元言語、主言語・副言語は独立しています。

初回ロードでは手元のゲームリソースを解析してキャッシュを作成するため、時間がかかることがあります。その後のテキスト描画にはゲーム本来の表示機能を使い、Qt の画面は設定と状態表示を担当します。ウィンドウまたはボーダーレス表示を利用してください。排他的フルスクリーンでは設定画面が表示されない場合があります。

### 多言語フォント

言語の組み合わせによっては、元のゲームフォントにない文字が「?」になるため、拡張フォントが必要です。ツールがゲームの場所を見つけると、手元のゲームリソースから自動でフォントを準備します。ゲーム実行中は準備だけを行い、終了後に安全に導入し、次回起動時に有効になります。ゲームのフォントは配布せず、OFL に基づく補助字形2文字のみを同梱します。

通常は手動操作は不要です。自動準備に失敗した場合の調査または再試行に限り、次のコマンドを使います。

```powershell
$runtime = Get-Content runtime/current.txt
& ".\runtime\$runtime\python.exe" -m sora_bilingual.fonts.install_font_patch --game "ゲームのインストール先" --install
```

インストーラーには監査済みの [sora2looseload](https://github.com/lmaple0/sora2looseload) ローダー（SHA-256 **e08a18068a482bb5d187a62023759c0e14ab69d76395b773ef0405d35e2ac8c7**）が含まれます。不一致の検証を無効化せず、他の Mod が所有するファイルは上書きしません。

## 操作と設定

小さなステータスバーの **設定** を押すと詳細パネルが開き、もう一度押すと閉じます。バーの文字、空白、ハンドル、またはパネル上部をドラッグすると両方が一緒に移動します。ボタンは従来どおりクリックできます。**詳細パネル内の × / Esc** はパネルだけを閉じます。**ステータスバーの ×** は画面を隠しますが、バックグラウンド動作は継続します。システムトレイまたはデスクトップのショートカットから再表示できます。

| 操作 | 初期ショートカット |
|---|---|
| 画面の表示・非表示 | Ctrl + Shift + F9 |
| 選択中のモードで言語を切り替え | Ctrl + Shift + F10 |

「ショートカット」でキーボードまたは SDL コントローラーの組み合わせを一つ登録します。同じ割り当てが選択中のモードに従います。既存のカスタム割り当ては移行され、F11/F12 は別の同時有効な操作としては使用しません。標準ではゲームが前面にある間に反応します。

- **二言語モード**：ゲーム本来のルビ機能で二言語を同時表示します。ショートカットで副言語の表示を切り替えます。
- **単一言語モード**：「押して切り替え」または「押している間だけ副言語」を選びます。押し続けても再切り替えせず、後者は離すかゲームが前面でなくなると主言語に戻ります。

文字サイズ、位置、間隔はその場で調整でき、メニューを開き直しても設定を維持します。間隔はエンジンが計測した文字の境界から算出します。
二言語全体の上下移動は標準で 0、正の値で下方向に移動し、単一言語モードには適用しません。副言語の色は元の RGB に係数を掛け、不透明度は元のアルファに掛けます。初期値は RGB 230 / 230 / 230（各値を 255 で割った係数）、不透明度 90% です。色ボタンの下のスライダーで不透明度を直接調整できます。主言語の色とアイコンのサイズは維持します。

ゲームの起動待ち中にインストール済みリソースを探し、選択中の言語ペアのキャッシュを準備します。初回やリソース・解析処理の変更後は一度だけ準備が必要です。先にツールを開き、準備完了後にゲームを起動できます。有効なキャッシュは直接読み込み、モデル全体の分割転送を省きます。オフラインの検証用プロセスでは、キャッシュを利用した接続処理は約 3.5–3.7 秒でした。ゲームの初期化時間は別途必要です。実際の接続時間はログに記録します。画面の翻訳や初期言語設定の変更だけでは索引を再構築しません。

メニュー、アイテム、スキル、NPC の会話、会話履歴、アクティブボイス、カットシーン字幕は、すべて主言語の上に小さな注釈を左揃えで表示します。本文に副言語の段落を追加しません。原文のルビや傍点は元の位置に残し、副言語には別の注釈領域を使います。画像や動画に焼き込まれた文字は対象外です。対応するテキストを確定できない場合は、推測で置き換えず原文を保持します。

## 推奨設定と既知の制限

快適さを優先する場合は **単言語モード → 押している間だけ副言語**（旧版の長押し切り替え）を選び、押しやすいキーボードまたはコントローラーの組み合わせを登録してください。普段は主言語だけを表示し、比較するときに押し、離すと戻ります。二言語を常時同時に組版しないため、現在の日常利用向けの推奨設定です。切り替え時には短い再レイアウトが発生する場合があり、遅延が完全になくなるとは限りません。

- **二言語の会話履歴には、未解消の性能上の制限があります。** 開く際に一瞬止まったり、表示中のフレームレートが単言語より低下したりする場合があります。実機では約 **700 ms** の停止が報告されており、開き直した場合にも発生します。履歴量、言語の組み合わせ、機器によって変わります。キャッシュとネイティブ処理の最適化で一部の負荷は軽減されていますが、解消済みではありません。気になる場合は上記の単言語・長押し切り替えで履歴を閲覧してください。
- **負荷はフォント描画だけでなく、レイアウトと解析にもあります。** 二言語表示はゲーム本来のルビ機能を利用します。履歴をまとめて処理し、表示中も一部のテキストを繰り返し解析するため、副言語の色や不透明度を変えてもこの処理は省略されません。
- **言語ペアの初回準備には時間がかかります。** 初回接続、未キャッシュの組み合わせ、ゲームリソースの変更時にはローカルリソースの処理が必要です。先にツールを起動して準備を完了させておくことをお勧めします。これは履歴を開く際の停止とは別の処理です。
- **対応範囲と表示領域には限界があります。** 対応関係が不明な文章は原文を保持し、画像・動画に埋め込まれた文字は処理しません。二言語表示によって固定テキスト枠が広がるわけではないため、長文や大きな文字では窮屈になる場合があります。文字を小さくするか、単言語モードを利用してください。ゲーム全体とすべての言語ペアの検証は完了していません。

## 自動更新

**更新**タブには **自動更新** のオン・オフだけがあります。初期値はオンで、起動時と六時間ごとに安定版を確認します。オフでは自動確認・インストールを停止し、手動確認は引き続き使えます。旧設定の「通知のみ」はオフとして扱い、勝手にインストールを有効にしません。

更新パッケージはバックグラウンドで取得し、リポジトリ、バージョン、ファイル一覧、SHA-256 を検証します。ゲームに接続している間は適用を待ち、接続終了後にインストールします。画面は自動で再読み込みされ、位置と展開・非表示状態を復元します。設定とキャッシュは **generated/**、依存ライブラリは **runtime/** に保持します。更新が中断された場合、次のショートカット起動時に適用を完了するか旧ファイルへ復元します。バックアップは **generated/updates/backup-*** にあります。

自動インストールは **installed-manifest.json** を含む配布版が対象です。Git の開発フォルダーや、手動変更されたソフトウェアファイルは上書きしません。ランタイム更新は別のバージョン用フォルダーに適用し、画面の再読み込み時に切り替えます。使用中の DLL は上書きしません。旧ランタイムは復旧用に残り、追加のディスク容量を使用します。ドラフト、プレリリース、旧バージョンは自動導入しません。

## 開発とコントリビュート

```powershell
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[dev]"
.venv\Scripts\python.exe -m tools.dev check
```

**tests/check_overlay_update.py** は独立した設定で Qt 画面の再読み込みを検証し、ゲームには接続しません。**tests/check_native_transport.py** はローカルのリソースを必要とし、自分で生成したテスト用プロセスだけに接続します。これらはゲーム不要の CI 単体テストとは別の統合テストです。

開発中の変更は **python -m tools.dev publish-local** で構文検証後にアトミックに公開できます。画面とテキスト処理はホットリロードし、常駐フックの変更は次回のゲーム起動を待ちます。ゲームの実行中に注入済みスクリプトを強制終了・アンロードしないでください。

[アーキテクチャ](https://github.com/Llugaes/bilingual-sora-2nd/blob/main/docs/ARCHITECTURE.md)と[貢献ガイド](https://github.com/Llugaes/bilingual-sora-2nd/blob/main/CONTRIBUTING.md)は現在中国語です。Issue・Pull Request を歓迎します。不具合報告にはツールとゲームのバージョン、言語の組み合わせ、再現手順、必要最小限のエラー情報を添えてください。ゲームデータ全体はアップロードしないでください。

公開時は **distribution.json** と **pyproject.toml** のバージョンを揃え、対応する **vX.Y.Z** タグを push します。GitHub Actions が Windows 上で検証し、明示したファイル一覧から ZIP を生成します。すべての配布ファイルをドラフトへアップロードした後、まとめて公開します。手動ビルド：

```powershell
.venv\Scripts\python.exe -m tools.build_portable --version 0.3.9 --repository Llugaes/bilingual-sora-2nd
```

リポジトリと配布パッケージには、ゲームリソース、生成フォント、完全なテキスト索引、ログ、スクリーンショット、ユーザー設定を含めません。
